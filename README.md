A collection of Bash scripts that automate the end-to-end deployment of Roboshop, a microservices-based e-commerce application. Covers provisioning and configuration of core components — MongoDB, Redis, MySQL, RabbitMQ — alongside application services (catalogue, cart, user, shipping, payment, frontend), using systemd unit files, Nginx reverse proxy config, and Nexus/Yum repo definitions for a fully automated, repeatable setup.
